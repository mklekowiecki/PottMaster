# Glaze Management - Quick Start Guide

## Overview
The glaze management system allows you to track your glaze inventory with comprehensive details including firing parameters, appearance properties, and usage notes.

## Getting Started

### Adding Your First Glaze

1. **Navigate to Inventory Tab**
   - Tap the "Inventory" tab in the bottom navigation

2. **Tap the + Button**
   - Large floating action button in bottom-right corner

3. **Fill in Basic Information (Required)**
   - **Glaze Name*** - Required field (e.g., "Amaco Celadon")
   - Manufacturer (optional)
   - Batch Date (optional)
   - Glaze Type: Low-fire / Mid-range / High-fire
   - Color
   - Cone Rating (e.g., "Cone 6")
   - Quantity (e.g., "500g" or "half jar")

4. **Set Food Safety**
   - Tap "Not Tested" (default)
   - Or "Safe" for food-safe glazes
   - Or "Not Safe" for decorative-only glazes

5. **Mark as Favorite (Optional)**
   - Check the "Mark as Favorite" checkbox for frequently used glazes

6. **Add Notes (Optional)**
   - Use the Notes field for any additional information

7. **Tap Save**

That's it! Your glaze is now saved locally and will appear in your inventory.

## Managing Your Glazes

### Search
- Use the search bar at the top
- Searches: name, manufacturer, color, cone rating

### Filter
- Toggle the checkbox next to search to show only favorites

### Mark as Favorite
- Tap the star icon on any glaze card
- Favorites appear at the top of the list

### Delete a Glaze
- Swipe left on any glaze card
- Tap the red "Delete" button
- Confirm deletion

### View Details
- Tap anywhere on a glaze card
- View all properties in organized sections
- (Coming soon: Edit from detail page)

## Pro Tips

### Organizing Your Glazes
1. Mark your most-used glazes as favorites
2. Use consistent naming (e.g., "Brand - Color - Cone")
3. Fill in cone rating for easy filtering
4. Note food safety status for functional ware

### Quick Entry
- Only glaze name is required
- Add details later as you learn about the glaze
- Use tabs to organize information

### Search Tips
- Search by manufacturer to find all glazes from a brand
- Search by cone rating to find glazes for specific firing
- Search by color for color coordination

### Offline Usage
- All glaze operations work offline
- Changes sync automatically when online
- "PENDING" status indicates unsynchronized changes

## Common Workflows

### Adding a New Glaze Purchase
1. Tap + button
2. Enter name and manufacturer
3. Add batch date (today's date)
4. Record cone rating from label
5. Note quantity purchased
6. Save

### Recording Test Results
1. Find glaze in inventory
2. Tap to view details (when implemented)
3. Edit to add firing results
4. Update appearance properties
5. Note any defects or special behaviors
6. Save updates

### Planning a Firing
1. Toggle "Favorites Only" to see commonly used glazes
2. Search by cone rating (e.g., "Cone 6")
3. Review type badges to ensure compatibility
4. Check food safety if planning functional ware

## Troubleshooting

### Glaze Not Saving
- Ensure glaze name is filled in (required field)
- Check internet connection for sync
- Look for error messages

### Can't Find a Glaze
- Check search spelling
- Clear search filter
- Turn off "Favorites Only" filter
- Verify glaze wasn't accidentally deleted

### Sync Issues
- Check sync status indicator at top of screen
- Ensure you're logged in
- Wait for automatic sync retry
- Check internet connection
